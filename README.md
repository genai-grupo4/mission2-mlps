## Ejecución
1. Crear un entorno virtual (opcional pero recomendado): `python3 -m venv venv && source venv/bin/activate`
2. Instalar dependencias: `pip install -r requirements.txt`
3. Verificar que `house-prices-extended.csv` esté en el mismo directorio que el notebook.
4. Abrir y correr `leichen_ciordia_monteverdi_serebrinsky.ipynb` con Jupyter: `jupyter notebook` (o `jupyter lab`).
